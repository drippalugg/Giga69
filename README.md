# MasterParts — Магазин автозапчастей

Десктопное приложение на JavaFX для просмотра каталога автозапчастей, управления корзиной и оформления заказов. Backend — Supabase (PostgreSQL) через REST API.

## Возможности

- Просмотр каталога запчастей с фильтрацией по категории и поиском по названию
- Карточка товара с описанием, ценой, скидкой и отзывами покупателей
- Добавление товаров в корзину и оформление заказа
- История заказов с отображением состава позиций, суммы и статуса
- Избранные товары с возможностью переноса в корзину
- Авторизация и регистрация пользователей через Supabase Auth
- Панель администратора для управления товарами и заказами
- Система отзывов и рейтингов товаров

## Стек технологий

- **Java 21** — язык разработки
- **JavaFX** — UI-фреймворк
- **FXML + CSS** — разметка и стилизация интерфейса
- **Supabase** — backend (PostgreSQL + Auth + REST API)
- **Gson** — парсинг JSON
- **Maven** — сборка проекта
- **JUnit 5** — модульное тестирование

## Структура проекта

- `controller/` — JavaFX-контроллеры экранов (Main, Cart, Orders, Favorites, Profile, AdminPanel и др.)
- `model/` — модели данных (Part, CartItem, Order, Review)
- `service/` — бизнес-логика и работа с Supabase (CartManager, PartsService, OrdersService, ReviewService, SupabaseAuthService, SupabaseClient)
- `util/` — вспомогательные классы

## Архитектура

Приложение построено по паттерну MVC. Слой Model содержит классы Part, CartItem, Order и Review. Слой View — FXML-файлы и CSS-стили. Слой Controller — JavaFX-контроллеры, обращающиеся к сервисам. Взаимодействие с базой данных осуществляется через SupabaseClient, который отправляет HTTP-запросы (GET, POST, PATCH, DELETE) к REST API Supabase.

## Запуск

Для запуска необходима Java 21 или выше. Клонируйте репозиторий, откройте проект в IntelliJ IDEA и запустите MainApp.java.

## Тестирование

Модульные тесты написаны на JUnit 5 и покрывают классы Part, CartItem, Order, Review. Тесты проверяют чистую бизнес-логику без сетевых запросов. Запуск: `mvn test`
